# Model check from Flash

This application sends the decoded physical values from
`rule_check_from_flash/raw_rows.h` through the row queue. The application scales each
row, runs one autoencoder, and calculates its reconstruction score and whether that
score is above the threshold. Only model execution and row scaling are shared libraries; the scoring
policy belongs to this application.

[`board/lib/active_model/`](../../lib/active_model) contains `nonlinear_ae_k8_h128_float`, generated by ST Edge AI v4.0.1
for STM32H5 with the st-ai API. [fetch_model](../../fetch_model.py) writes it from the
runs repository, `board/20260928-200316/nonlinear_ae_k8_h128/`, named `instant_model` by
[generate_model_for_board](../../../deploy/docs/generate_model_for_board.md).

`model_config.h` keeps the scale of `models/20260928-112526`, the fit the model came
from. `threshold.h` keeps the threshold of `thresholds/20260928-114811`.
`instant_model.onnx` is the float model the C was generated from.

## Fixed model input contract

`board.prepare` does not fetch or generate a model. Before prepare, build and flash,
[fetch_model](../../fetch_model.py) places these files in `board/lib/active_model/`:

- `instant_model.c`
- `instant_model.h`
- `instant_model_data.c`
- `instant_model_data.h`
- `instant_model_details.h`
- `model_config.h`
- `threshold.h`

The generated C must use the st-ai API, expose `stai_instant_model_*`, take and return
one float32 tensor of 17 values, and target the runtime supplied at build time.
`model_config.h` must define `INSTANT_MODEL_ID`, `instant_model_mean` and
`instant_model_std` for the same model, and `threshold.h` its `THRESHOLD_SCORE`.
`LICENSE.txt` is retained with the fixed model but is not a compiler input.

Changing models later means atomically replacing this set while keeping the file and
symbol contract. Fetching and conversion remain outside `board.prepare`.

## Prepare, build and flash

ST Edge AI v4.0 is read from `stedgeai` in `board/paths.json`.

```sh
python3 -m board.prepare model_check_from_flash
python3 -m board.flash
```

Prepare adds ST Edge AI's `Middlewares/ST/AI/Inc` headers and links
`NetworkRuntime1201_CM33_GCC.a`. These are board build dependencies, not model inputs.

## Check on the board

ONNX Runtime flags rows 1253 to 1312 of the 80 rows, 60 rows in all. This was run on
2026-09-28 with `board/lib/active_model/instant_model.onnx`. The board should
print the same count on its last UART line:

```
model: processed 80/80, flagged_rows 60, dropped 0, errors 0, max_cycles ...
```

`max_cycles` is the longest inference in CPU cycles. On 2026-09-29 the Release build, at
`-O2` and 32 MHz, printed `flagged_rows 60` and `max_cycles 55938`, 1.75 ms.
