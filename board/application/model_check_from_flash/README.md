# Model check from Flash

This application sends the decoded physical values from
`rule_check_from_flash/raw_rows.h` through the row queue. The application scales each
row, runs one autoencoder, and calculates its reconstruction score and anomaly
decision. Only model execution and row scaling are shared libraries; the scoring
policy belongs to this application.

[`board/lib/active_model/`](../../lib/active_model) contains `nonlinear_ae_k8_h64_float`, generated by ST Edge AI v4.0.1
for STM32H5 with the st-ai API. The source came from the runs repository at
`board/20260916-232708/nonlinear_ae_k8_h64/`. Its generated `network` symbols and file
names are renamed to the stable application name `active_model`.

`model_config.h` keeps the matching scale from `out/scale.npy`. `threshold.h` keeps the
float-model threshold from `results/20260916-001002` (`0.041679270565509796`).

## Fixed model input contract

`board.prepare` does not fetch or generate a model. Before prepare/build/flash, the
pipeline (or a temporary manual step) must place these files in `board/lib/active_model/`:

- `active_model.c`
- `active_model.h`
- `active_model_data.c`
- `active_model_data.h`
- `active_model_details.h`
- `model_config.h`
- `threshold.h`

The generated C must use the st-ai API, expose `stai_active_model_*`, take and return
one float32 tensor of 17 values, and target the runtime supplied at build time.
`model_config.h` must define `ACTIVE_MODEL_ID`, `active_model_mean` and
`active_model_std` for the same model, and `threshold.h` its `THRESHOLD_SCORE`.
`LICENSE.txt` is retained with the fixed model but is not a compiler input.

Changing models later means atomically replacing this set while keeping the file and
symbol contract. Fetching, conversion and renaming remain outside `board.prepare`.

## Prepare, build and flash

ST Edge AI v4.0 is read from `/Applications/ST/STEdgeAI/4.0` by default. Override it
with `STEDGEAI_ROOT` or `--stedgeai-root`.

```sh
python3 -m board.prepare CUBEIDE_PROJECT_DIR model_check_from_flash
python3 board/flash.py CUBEIDE_PROJECT_DIR
```

Prepare adds ST Edge AI's `Middlewares/ST/AI/Inc` headers and links
`NetworkRuntime1201_CM33_GCC.a`. These are board build dependencies, not model inputs.
